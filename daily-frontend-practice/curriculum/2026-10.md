# 2026 年 10 月：前端综合与面试输出

> 本月目标：把单题能力迁移到真实前端问题。每天继续四题；每个题目文件由老师直接给出中文解释、输入、输出、具体例子和关键边界，学习者再补充状态、复杂度或取舍。周末安排限时模拟与间隔复习。

## 第 1 周：图、堆与并发调度

### 10-01

- A 课程表：判断有向图是否存在环；用入度拓扑排序或 DFS 染色，并说明选择。
- B Promise 并发池复现：最多并发 limit 个任务，按输入顺序返回结果，reject 后不再领取新任务。
- C 浏览器连接限制：解释同源 HTTP/1.1 与 HTTP/2 多路复用对并发请求策略的影响。
- D 下载管理器：实现排队、并发数、暂停等待任务、重试失败任务的状态机。

### 10-02

- A 课程表 II：返回一条合法学习顺序；无解返回空数组。
- B 手写 `Promise.prototype.finally` 行为：无论成功失败都执行回调，并保持原结果或原错误。
- C HTTP/2 与 HTTP/3：说明队头阻塞的差异及 QUIC 的作用。
- D 任务队列面板：展示 pending/running/success/error 四类任务数量和顺序。

### 10-03

- A 第 K 大元素：用最小堆或快速选择实现；不得直接完整排序作为最终方案。
- B 手写异步 `retry`：支持最大次数、固定/指数间隔、成功即停止、最后一次错误透传。
- C 重试幂等性：解释哪些 HTTP 方法通常适合重试，哪些需要业务幂等键。
- D 接口重试策略：根据状态码决定是否重试，并记录每次尝试的时间与原因。

### 10-04

- A 前 K 个高频元素：统计频次后用桶或堆返回前 k 个；处理频次相同时的规则。
- B 手写 `sleep(ms)` 与超时包装：超时后 reject，不让晚到结果覆盖当前状态。
- C AbortController 复习：解释一次取消如何传播到 fetch 和业务状态。
- D 搜索请求竞态：快速输入时只接受最后一个请求结果，旧请求要取消或忽略。

### 10-05

- A 最小栈：支持 push/pop/top/getMin，所有操作 `O(1)`。
- B 手写 `once(fn)`：无论成功失败只执行一次，并说明异步函数的缓存策略。
- C 长任务：解释 Long Task、主线程阻塞与 PerformanceObserver。
- D 分片计算器：大数组求和分帧执行，实时报告进度，可随时取消。

### 10-06

- A 每日温度：单调栈返回每一天等待更高温度的天数。
- B 手写 `memoize`：按参数缓存结果，提供 cache.clear；说明对象参数的局限。
- C 缓存键设计：解释 URL、method、body、用户身份如何影响缓存正确性。
- D 查询缓存：支持 key、过期时间、失效、正在请求去重和手动刷新。

### 10-07（限时复习）

- A 单调栈变式：下一个更大元素；数组循环一次后仍能查找。
- B Promise 并发池：30 分钟独立重写，写出 index、running、results 的职责。
- C 异步面试口述：用 2 分钟说明 Promise、async/await、微任务与并发池的关系。
- D 代码审查：为一个“请求全部同时发出”的伪并发池列出三个可观测错误。

## 第 2 周：动态规划、排序与前端数据流

- B 手写 `sortBy`：按多个字段稳定排序，支持 asc/desc 与空值放末尾。

- D 购物车 reducer：支持增减数量、删除、勾选、全选、总价；每个 action 纯函数实现。

### 10-09

- C 不可变更新：解释浅拷贝为何不等于深拷贝，以及嵌套状态更新风险。

### 10-10

- C React 渲染基础：解释 key 的作用以及使用 index 作为 key 的风险。
- D 列表 key 检查器：给定旧新列表，识别重复 key、缺失 key、疑似 index key。

### 10-11

- A 最大子数组和：Kadane 算法，返回最大和及对应区间。
- B 手写 `chunk`：按 size 切分数组；非法 size 抛 RangeError。
- C 前端分页：比较页码分页、游标分页、无限滚动的适用场景。
- D 分页控制器：处理 page、pageSize、总数、越界页码和请求 loading 状态。

### 10-12

- A 接雨水复习：不用辅助数组，用双指针计算。
- B 手写 `uniqBy`：按 key 或回调去重，保持第一次出现顺序。
- C 乐观更新：解释先更新 UI、失败回滚、重复提交防护。
- D 点赞按钮：乐观加一，接口失败回滚；快速连点只允许最后状态生效。

### 10-13

- B 手写 `pick/omit`：仅复制自有可枚举属性，保持输入对象不变。
- C 表单受控与非受控：比较数据来源、校验、性能与适用场景。
- D 动态表单：按 schema 渲染字段，支持依赖显示、校验、重置与提交值收集。

### 10-14（限时复习）

- B `groupBy + sortBy` 组合题：按部门分组后按薪资降序，每组保持稳定规则。
- C 前端状态题：为“列表筛选 + 分页 + 搜索”画状态图，说明何时重置 page。
- D 45 分钟模拟：从本周任选算法题和手写题各一，独立完成并写测试。
