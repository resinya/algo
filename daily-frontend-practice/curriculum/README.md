# 两个月前端面试训练日历

本目录保存尚未开始的训练排期，不替代 `days/YYYY-MM-DD/` 中的当天练习材料。

- 每天固定 4 题：`A` 算法 / 数据结构，`B` JavaScript 手写，`C` 浏览器、网络或异步，`D` 小功能或工程实践。
- 每条都用中文写明最低要求与验收点；每个独立模块由老师直接提供中文题意、输入、输出、具体例子、关键边界、代码骨架与测试。
- 学习者编码前先复述已给出的输入输出，并画出维护的状态；完成后再写时间和空间复杂度。
- 周末不是休息题：用于变式复习、限时模拟和已做题的重新实现，用来检验长期保持。
