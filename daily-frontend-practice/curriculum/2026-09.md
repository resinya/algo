# 2026 年 9 月：高频基础与状态建模

> 本月目标：建立“先定义状态和不变式、再写循环”的习惯。每天四题中，A/B/C/D 分别对应算法、JavaScript 手写、浏览器/异步、工程小功能。每道题均需要写中文注释说明核心状态与边界。

## 第 1 周：数组、字符串、Map 与栈

### 09-01（已创建当天题目）

- A 最短长度子数组：用滑动窗口找和至少为 `target` 的最短连续子数组；无解返回 `0`，要求 `O(n)`。
- B 合并区间：按起点排序后合并有重叠或相接的区间；不得修改输入，明确排序复杂度。
- C 手写 EventEmitter：支持 `on`、`off`、`once`、`emit`；同一事件的回调按注册顺序执行。
- D 搜索历史模块：实现添加、去重置顶、最多保留 10 条、清空与本地持久化的纯逻辑层。

### 09-02

- A 两数之和变式：返回所有不重复的数值对下标；同一元素不能重复使用，目标 `O(n)`。
- B 数组扁平化：实现 `flat(array, depth = Infinity)`；跳过稀疏数组空位，不能调用原生 `flat`。
- C 宏任务与微任务：预测给定 `Promise`、`queueMicrotask`、`setTimeout` 的打印顺序，并写出原因。
- D 防抖搜索框：实现 `debounce`，要求保留 `this`/参数并提供 `cancel`；用模拟输入验证只执行最后一次。

### 09-03

- A 三数之和：返回和为 0 的不重复三元组；排序后使用双指针，跳过重复答案。
- B 函数柯里化：实现 `curry(fn)`；参数凑够后执行，支持一次传多个参数。
- C 事件委托：为动态列表设计点击处理函数；用 `closest` 找目标，并说明为什么比逐项绑定更省资源。
- D Todo 数据层：实现新增、切换完成、删除、筛选和统计；所有更新必须返回新数组。

### 09-04

- A 最长回文子串：返回最长连续回文串；使用中心扩散，处理奇偶长度中心。
- B 手写 `call`：实现 `myCall`，支持普通参数与临时属性清理；说明箭头函数为何不适用。
- C URL 与 URLSearchParams：分别用原生 API 解析查询参数、重复键和 hash；比较其与手写解析器的取舍。
- D 表格排序器：支持单列升降序、数字/中文字符串/空值；不得修改原始列表。

### 09-05

- A 有效的括号变式：除判断有效外，返回第一个错误位置；无错误返回 `-1`。
- B 手写 `bind`：实现预置参数、调用时参数追加，并处理作为构造函数调用的场景。
- C Cookie、localStorage、sessionStorage：写出三者对比表，并实现安全读写 JSON 的工具函数。
- D 表单校验器：配置式支持 required、minLength、pattern；输出字段错误信息对象。

### 09-06

- A 无重复字符最长子串变式：返回最长子串本身及其起止下标；要求 `O(n)`。
- B 发布订阅器：支持通配事件 `*` 与 `once`；移除监听后不得残留引用。
- C 浏览器渲染流程：解释 JS、style、layout、paint、composite 的顺序，并指出读写布局如何造成强制同步布局。
- D 虚拟列表计算器：给定滚动距离、行高、视口高度，计算应渲染的起止下标与上下占位高度。

### 09-07（限时复习）

- A 反转字符串中的单词：去除多余空格后反转单词顺序；不使用正则的一步到位答案。
- B `Object.is` 模拟：正确区分 `NaN` 与 `+0/-0`。
- C HTTP 状态码分类：为 200、201、204、301、304、400、401、403、404、429、500 写出前端处理策略。
- D 30 分钟模拟：从本周任选一题重写；先写状态注释，再实现，再自行设计 3 个边界测试。

- D 加载按钮：实现防重复点击、加载文案、成功/失败恢复；状态更新需可测试。

- D 文件上传队列：维护待上传、上传中、成功、失败四类文件；支持重试失败项。

### 09-11

- A 二分查找：在有序数组中找目标，找不到返回 `-1`；明确循环不变式与边界区间。
- B 防抖与节流对比：分别实现 `debounce`、`throttle`；说明输入搜索与滚动监听的选择。
- C CORS：解释简单请求、预检请求、credentials 与常见失败原因。
- D 可取消请求管理器：同一 key 的新请求启动时取消旧请求，最新结果才允许写入状态。

### 09-12

- A 搜索旋转排序数组：无重复数字，要求 `O(log n)`；判断哪一半有序。
- B 手写 `Promise.all`：保持输入顺序、空数组立即 resolve、任一 reject 立即 reject。
- C HTTP 缓存：比较强缓存与协商缓存，说明 `Cache-Control`、ETag、304。
- D 带缓存的请求函数：相同 key 在有效期内复用结果；支持手动失效。

### 09-13

- A 快速排序：实现纯函数版本；选择 pivot 并说明最坏情况。
- B 手写 `Promise.race`：第一个 settled 的结果决定返回 Promise；解释空数组行为。
- C Web Storage 异常：实现 `safeStorage`，处理 JSON 解析失败和不可用环境。
- D 草稿箱：输入变化后防抖保存，加载时恢复，提交成功后清除草稿。

### 09-14（限时复习）

- A 二分边界：分别实现第一个大于等于 target 与最后一个小于等于 target 的位置。
- B Promise 并发池：最多同时执行 `limit` 个任务，按输入顺序返回结果，失败后停止领取新任务。
- C 网络面试口述：用 2 分钟解释一次从输入 URL 到页面显示的关键链路。
