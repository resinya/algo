# Teaching Notes

- 学习者希望我扮演长期的算法与前端手写老师。
- 每天固定 4 题；题目来源可以是学习者，也可以由我按市场常见题生成。
- 可选范围：前端知识、算法、JavaScript 手写、工程实践、vibe coding 小功能。
- 教学方式：先给完整题目信息和代码骨架，学习者写完后再讲解与点评。
- 需要持续在本教学目录中记录题目、代码、教学约定和已证实的学习进展。
- 教学材料统一隔离在 `daily-frontend-practice/`，不改动父目录其他内容。
- 现有 `手撕/01数组转树.js` 是学习者未提交的文件，保持不覆盖。
- 学习者希望持续维护一份动态能力画像，根据每次回答和代码更新薄弱项与出题方向。
- 能力判断必须基于证据；没有提交过的方面标记为“未评估”，不要猜测。
- 学习者通常会把不会写、未完成或报错的代码直接粘贴到对话中，不要求先写入仓库或正式提交。
- 默认采用逐步指导：一次解决一个最小卡点，等待学习者自己修改，并在互动过程中同步记录能力缺口。
- 当题目包含嵌套循环、状态变量或父子连接时，学习者容易只看代码而失去整体数据流；优先提供流程图、单个样例的变量跟踪表，再回到代码。
- 学习者明确希望提升“拿到题目后形成思路”的能力；后续要求先画输入输出和单样例执行过程，不直接从空函数开始敲实现。
