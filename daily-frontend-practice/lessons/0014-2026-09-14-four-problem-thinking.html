前端每日四题 · 2026-09-14

先看状态，再写代码

这一页覆盖当天四题。目标不是记答案，而是能在动手前说清楚：状态、更新时机、边界和验证方法。

统一破题顺序：题目约束 → 输入输出 → 状态/数据结构 → 单样例变化 → 边界 → 代码与断言。

第 1 题 · 算法 / 数据结构

二分边界

二分边界：分别实现第一个大于等于 target 与最后一个小于等于 target 的位置。

破题点

先不要写代码：把题目拆成“状态保存什么、何时更新、何时停止或返回”。

可视化解题路径

1. 写清搜索区间含义只处理当前一步
2. 计算中点并判断单调侧只处理当前一步
3. 丢弃不可能区间只处理当前一步
4. 处理 left/right 相遇边界只处理当前一步

写前检查

  • 能否说出核心数据结构为何适合？
  • 循环/递归的不变式是什么？
  • 空输入、无解或重复值如何处理？
  • 时间与空间复杂度是什么？

第 2 题 · JavaScript 手写

Promise 并发池

Promise 并发池：最多同时执行 `limit` 个任务，按输入顺序返回结果，失败后停止领取新任务。

破题点

先不要写代码：把题目拆成“状态保存什么、何时更新、何时停止或返回”。

可视化解题路径

1. 明确 resolve/reject 契约只处理当前一步
2. 定义共享状态与初始值只处理当前一步
3. 在 settled 后更新状态只处理当前一步
4. 验证顺序、失败和取消只处理当前一步

写前检查

  • 输入、this、异常或 Promise 的契约是什么？
  • 状态在哪一刻更新才正确？
  • 是否修改了输入或残留副作用？
  • 至少一个边界断言是什么？

第 4 题 · 工程小功能
