前端每日四题 · 2026-09-02

先看状态，再写代码

这一页覆盖当天四题。目标不是记答案，而是能在动手前说清楚：状态、更新时机、边界和验证方法。

统一破题顺序：题目约束 → 输入输出 → 状态/数据结构 → 单样例变化 → 边界 → 代码与断言。

第 1 题 · 算法 / 数据结构

两数之和变式

两数之和变式：返回所有不重复的数值对下标；同一元素不能重复使用，目标 `O(n)`。

破题点

先不要写代码：把题目拆成“状态保存什么、何时更新、何时停止或返回”。

可视化解题路径

1. 翻译输入输出与约束只处理当前一步
2. 选择最小必要数据结构只处理当前一步
3. 维护循环/递归不变式只处理当前一步
4. 用边界样例验证答案只处理当前一步

写前检查

  • 能否说出核心数据结构为何适合？
  • 循环/递归的不变式是什么？
  • 空输入、无解或重复值如何处理？
  • 时间与空间复杂度是什么？
