先识别“关系藏在哪里”

今天的四题表面上都在处理字符串或数组，真正的训练点是：先找到关系的载体，再选择索引、逐段扫描或增量建树。不要急着写循环，先说出数据之间如何关联。

01

列表转树

关系藏在 id 与 parentId 中。

02

URL 参数

结构藏在 ?、&、= 和编码规则中。

03

路由树

层级藏在路径的公共前缀中。

04

版本比较

顺序藏在逐段数值语义中。

今天只练一个动作

口述关系 → 列边界 → 选数据结构 → 写最小实现 → 跑测试 → 解释复杂度
