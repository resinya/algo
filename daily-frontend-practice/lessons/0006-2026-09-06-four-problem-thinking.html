先看状态，再写代码

这一页覆盖当天四题。目标不是记答案，而是能在动手前说清楚：状态、更新时机、边界和验证方法。

统一破题顺序：题目约束 → 输入输出 → 状态/数据结构 → 单样例变化 → 边界 → 代码与断言。

2. 右边扩张纳入新元素只处理当前一步
3. 满足条件时收缩左边只处理当前一步
4. 记录最优答案与边界只处理当前一步

写前检查

  • 能否说出核心数据结构为何适合？
  • 循环/递归的不变式是什么？
  • 空输入、无解或重复值如何处理？
  • 时间与空间复杂度是什么？
