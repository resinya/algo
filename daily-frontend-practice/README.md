# Daily Frontend Practice

这是独立的前端算法、JavaScript 手写与小功能训练区，不影响父目录现有代码。每天的题目、实现和复盘都保存在 `days/` 中：

```text
days/YYYY-MM-DD/
├── questions.md
├── 01-*.js
├── 02-*.js
├── 03-*.js
└── 04-*.js

learner-profile/
├── CURRENT.md
└── assessments/
```

## 推荐节奏

1. 先读四题，自己补充容易遗漏的边界。
2. 每题先口述思路，再开始写代码。
3. 卡住时可以直接把当前代码贴到对话中，不需要保存或正式提交。
4. 老师一次只带你解决一个最小问题；你修改后再继续下一步。
5. 能运行时执行 `node 文件名.js` 进行测试，并根据失败结果继续定位。
6. 完成后复盘正确性、复杂度、可读性、边界和面试表达，同时更新学习状态。

## 每个练习文件会直接提供

- 中文题意：说明这道题实际要解决什么。
- 输入：参数、数据结构或待分析场景的具体形态。
- 输出：函数返回值，或概念题需要交付的判断与策略。
- 具体例子：至少一个输入与对应结果，并解释为什么。
- 边界：最容易遗漏的异常、空值或状态变化。

学习者仍需在编码前复述这些信息并画状态变化，但不需要猜测题目的输入输出。
