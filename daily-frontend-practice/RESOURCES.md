# 前端算法与手写训练资源

本清单仅服务于当前独立教学工作区。

## Knowledge

- [WHATWG URL Standard](https://url.spec.whatwg.org/)
  URL、查询字符串、百分号编码及 `URLSearchParams` 的规范来源。用于 URL 解析题的边界核对。
- [MDN: URLSearchParams](https://developer.mozilla.org/en-US/docs/Web/API/URLSearchParams)
  面向开发者的查询参数 API 说明。用于手写完成后与平台原生能力进行对照。
- [ECMAScript 2026: Indexed Collections](https://tc39.es/ecma262/2026/multipage/indexed-collections.html)
  数组方法与排序行为的语言规范。用于数组变换、排序和比较器题目。
- [ECMAScript 2026: Keyed Collections](https://tc39.es/ecma262/2026/multipage/keyed-collections.html)
  `Map`/`Set` 的规范来源。用于分析哈希索引和去重方案。
- [Node.js: Assert](https://nodejs.org/api/assert.html)
  Node 内置断言工具文档。每日代码骨架使用它提供即时反馈，不额外引入依赖。

## Wisdom (Communities)

- [Stack Overflow — JavaScript](https://stackoverflow.com/questions/tagged/javascript)
  用于观察真实工程边界和不同实现取舍；提问或采纳方案前需验证上下文与日期。
- [TC39 Discourse](https://es.discourse.group/)
  用于理解 JavaScript 语言设计与提案讨论，不作为基础刷题的必读材料。
