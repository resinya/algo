# 评估记录

每次对学习者的代码、答案或复习表现进行正式复盘时，在这里新增一份记录。文件名示例：

```text
2026-08-18-list-to-tree.md
2026-08-18-day-01-review.md
```

## 记录模板

```md
# 评估标题

- 日期：YYYY-MM-DD
- 证据来源：对话代码 / 仓库代码 / 文字回答 / 测试 / 间隔复习
- 对应题目或回答：相对路径，或“日期 + 题号/主题 + 卡点摘要”
- 独立程度：独立完成 / 一级提示 / 二级提示 / 三级提示 / 参考答案后完成
- 测试结果：通过数、失败数与关键失败原因

## 指导过程

- 初始卡点：学习者认为自己哪里不会，以及代码停在哪里。
- 最小提示：本轮只给了什么方向、反例或追问。
- 学习者反应：能否解释、修改和迁移。

## 做得好的地方

- 只写有具体证据支持的表现。

## 暴露的问题

- 现象：发生了什么。
- 原因：目前判断的根因；不确定时明确写假设。
- 影响维度：对应能力档案中的哪个维度。
- 证据强度：观察 / 普通证据 / 强证据。

## 本次状态变化

- 某维度：未评估 → 发展中（置信度：低）。
- 或：只有一次观察，暂不调整状态。

## 下一步训练

- 一个最小纠正动作。
- 一道用于验证迁移或长期保持的变式题。
```

记录完成后必须同步更新上一级的 [`CURRENT.md`](../CURRENT.md)，但不要因为一次粗心就夸大薄弱程度。
