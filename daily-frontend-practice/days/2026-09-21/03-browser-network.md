# 浏览器 / 网络 / 异步

## 题目要求

Web 安全基础：解释 XSS、CSRF、点击劫持，并各给一个前端防护措施。

## 中文解释（已给出）

- 意思：这道题要你分析或完成：Web 安全基础：解释 XSS、CSRF、点击劫持，并各给一个前端防护措施。
- 输入/场景：三个真实攻击场景：不可信 HTML、跨站转账、透明 iframe 诱导点击。
- 输出/作答：分别识别 XSS/CSRF/点击劫持，并给至少一个匹配的防护措施。
- 具体例子：把用户输入直接写入 innerHTML 可能造成 XSS，应做上下文转义/白名单清洗并配合 CSP。
- 关键边界：SameSite 防 CSRF 但不替代服务端 token；X-Frame-Options/frame-ancestors 防点击劫持。
