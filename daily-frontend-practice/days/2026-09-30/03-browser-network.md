# 浏览器 / 网络 / 异步

## 题目要求

前端错误监控：区分资源错误、运行时错误、Promise 未处理拒绝。

## 中文解释（已给出）

- 意思：这道题要你分析或完成：前端错误监控：区分资源错误、运行时错误、Promise 未处理拒绝。
- 输入/场景：资源加载失败、同步运行时异常和未处理 Promise 拒绝三个场景。
- 输出/作答：对应监听入口、统一错误字段和去重/采样策略。
- 具体例子：window error 捕获脚本异常；资源 error 需捕获阶段；unhandledrejection 读取 event.reason。
- 关键边界：监控代码自身不能再次抛错；跨域脚本可能只得到 Script error。
