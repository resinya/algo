## 中文解释（已给出）

- 意思：这道题要你分析或完成：React 渲染基础：解释 key 的作用以及使用 index 作为 key 的风险。
- 输入/场景：旧列表、新列表及每项 key，包含插入、删除和重排。
- 输出/作答：解释 key 如何帮助保持节点身份，以及 index key 的错误复用风险。
- 具体例子：在列表头插入新项时，稳定 id key 只新增一个节点；index key 会让后续输入框状态错位。
- 关键边界：key 只需在同级兄弟中唯一；它不是传给组件的普通 prop。
