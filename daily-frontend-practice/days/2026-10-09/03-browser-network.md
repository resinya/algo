# 浏览器 / 网络 / 异步

## 题目要求

不可变更新：解释浅拷贝为何不等于深拷贝，以及嵌套状态更新风险。

## 中文解释（已给出）

- 意思：这道题要你分析或完成：不可变更新：解释浅拷贝为何不等于深拷贝，以及嵌套状态更新风险。
- 输入/场景：一个嵌套状态对象及一次更新，例如只修改 user.address.city。
- 输出/作答：说明浅拷贝影响的层级、风险和正确不可变更新路径。
- 具体例子：{...state,user:{...state.user,address:{...state.user.address,city:"上海"}}} 才不会修改旧 address。
- 关键边界：浅拷贝只复制一层；共享嵌套引用可能让旧 state 被意外改变。
