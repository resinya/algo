# 浏览器 / 网络 / 异步

## 题目要求

可访问性基础：说明语义化、键盘焦点、aria-label 和对比度。

## 中文解释（已给出）

- 意思：这道题要你分析或完成：可访问性基础：说明语义化、键盘焦点、aria-label 和对比度。
- 输入/场景：一个只有图标的按钮、键盘用户和低对比度文字场景。
- 输出/作答：语义元素、焦点顺序、可访问名称和对比度的修正方案。
- 具体例子：<button aria-label="关闭">×</button> 可被键盘聚焦且读屏知道用途；不要用无 tabindex 的 div 模拟按钮。
- 关键边界：aria 不能修复错误交互语义；焦点样式不能只靠颜色且不应无故移除 outline。
