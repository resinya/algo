# 浏览器 / 网络 / 异步

## 题目要求

前端状态题：为“列表筛选 + 分页 + 搜索”画状态图，说明何时重置 page。

## 中文解释（已给出）

- 意思：这道题要你分析或完成：前端状态题：为“列表筛选 + 分页 + 搜索”画状态图，说明何时重置 page。
- 输入/场景：关键词 search、筛选 filter、页码 page 与请求状态。
- 输出/作答：状态图及每个事件后的 page 重置规则。
- 具体例子：用户在 page=4 修改 search -> page 重置为 1 后请求新条件；仅翻页不清空筛选。
- 关键边界：防抖搜索的旧请求不能覆盖新状态；URL 同步要避免循环更新。
