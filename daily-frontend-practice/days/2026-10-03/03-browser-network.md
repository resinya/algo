# 浏览器 / 网络 / 异步

## 题目要求

重试幂等性：解释哪些 HTTP 方法通常适合重试，哪些需要业务幂等键。

## 中文解释（已给出）

- 意思：这道题要你分析或完成：重试幂等性：解释哪些 HTTP 方法通常适合重试，哪些需要业务幂等键。
- 输入/场景：一个失败的 HTTP 请求，包含 method、状态码和可选业务幂等键。
- 输出/作答：判断能否自动重试，并给出原因与保护措施。
- 具体例子：GET /products 遇到 503 通常可重试；POST /orders 需幂等键，否则重复请求可能创建两笔订单。
- 关键边界：网络超时不代表服务端未处理；429 应结合 Retry-After。
