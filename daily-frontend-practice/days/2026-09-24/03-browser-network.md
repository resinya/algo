# 浏览器 / 网络 / 异步

## 题目要求

内存泄漏：列出闭包、定时器、监听器、DOM 引用造成泄漏的例子和清理策略。

## 中文解释（已给出）

- 意思：这道题要你分析或完成：内存泄漏：列出闭包、定时器、监听器、DOM 引用造成泄漏的例子和清理策略。
- 输入/场景：一段含闭包、定时器、DOM 监听和已移除节点引用的组件代码。
- 输出/作答：指出保留链、可观测症状、清理时机和验证方法。
- 具体例子：组件卸载后未 clearInterval，回调仍引用组件状态 -> 内存和 CPU 持续增长；destroy 中清理定时器。
- 关键边界：监听器必须用同一函数引用解除；用堆快照验证而不是凭感觉。
