# 浏览器 / 网络 / 异步

## 题目要求

HTTP 状态码分类：为 200、201、204、301、304、400、401、403、404、429、500 写出前端处理策略。

## 中文解释（已给出）

- 意思：这道题要你分析或完成：HTTP 状态码分类：为 200、201、204、301、304、400、401、403、404、429、500 写出前端处理策略。
- 输入/场景：一个 HTTP 状态码和当前请求场景。
- 输出/作答：状态含义、是否可重试、页面提示和登录/缓存等前端动作。
- 具体例子：401 -> 身份未认证，可尝试刷新登录态；403 -> 已认证但无权限，不应循环刷新 token。
- 关键边界：204 没有响应体；304 依赖本地缓存；429 应尊重 Retry-After。
