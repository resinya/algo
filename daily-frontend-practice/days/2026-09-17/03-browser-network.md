# 浏览器 / 网络 / 异步

## 题目要求

重绘与回流：列出会触发布局的操作，并为批量 DOM 更新给出优化方案。

## 中文解释（已给出）

- 意思：这道题要你分析或完成：重绘与回流：列出会触发布局的操作，并为批量 DOM 更新给出优化方案。
- 输入/场景：一组 DOM 读取/写入操作，例如改宽度、读 offsetHeight、改 class。
- 输出/作答：哪些操作可能回流/重绘，以及把读取和写入分批的优化方案。
- 具体例子：循环中每次 style.width=... 后读取 offsetWidth 会反复强制布局；先统一读取、再统一写入可减少抖动。
- 关键边界：transform/opacity 通常不触发布局；实际性能要用 DevTools 验证。
